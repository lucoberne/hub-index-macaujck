# hub-index-macaujck

## 项目简介

本项目是一个用于归档和发布多个独立 HTML 页面的仓库。页面内容不针对任何特定域名或网站，仅作为静态页面的集中存放与展示。

通过此仓库，可以方便地管理和分发多个独立的 HTML 资源，适用于需要长期保留或定期更新的页面归档场景。

## 目录结构

```
hub-index-macaujck/
├── pages/          # 存放主要 HTML 页面
├── assets/         # 页面引用的静态资源（如图片、样式、脚本）
├── index.html      # 仓库主页（可选）
└── README.md       # 本文件
```

- `pages/`：每个独立页面以文件或子目录形式存放，命名清晰，便于检索。
- `assets/`：公共资源文件，按类型或用途组织。

## 页面归档说明

仓库中的 HTML 页面均为独立归档，彼此之间无依赖关系。页面内容可能涉及信息展示、工具页面、临时存档等，具体用途见各页面内部说明。

页面更新时，建议保留历史版本，或通过 Git 提交记录追溯变更。对于不再维护的页面，可在文件名或目录名中添加 `_archived` 后缀以示区分。

## 维护说明

- 欢迎提交 Pull Request 新增或更新页面，但请确保内容不违反 GitHub 服务条款。
- 页面应尽量使用相对路径引用资源，以保证在本地或镜像环境中正常工作。
- 不建议在页面中包含外部追踪脚本、广告或恶意代码。
- 如需删除页面，请先确认无其他页面引用相关资源。
